DIAGRAMMES D'ACCORDS - application web installable (PWA)

Contenu : index.html (l'appli), manifest.webmanifest, sw.js (mode hors ligne), icônes.

1) HÉBERGER (obligatoire, en HTTPS)
Une PWA ne s'installe pas depuis un simple double-clic sur le fichier. Il faut la mettre en ligne en HTTPS. Les plus simples, gratuits :
 - Netlify Drop : sur app.netlify.com/drop, glisser le dossier décompressé.
 - GitHub Pages : créer un dépôt, y déposer tous les fichiers à la racine, puis Settings > Pages > Deploy from a branch.
Pour essayer sur ton ordinateur : dans le dossier, lancer « python3 -m http.server 8000 » et ouvrir http://localhost:8000 (localhost est accepté sans HTTPS).

2) INSTALLER
 - Android / Chrome : menu ⋮ > « Installer l'application ».
 - iPhone / iPad : Safari > bouton Partager > « Sur l'écran d'accueil ».
 - Ordinateur / Chrome ou Edge : icône d'installation dans la barre d'adresse.
Après la première visite en ligne, l'appli fonctionne sans connexion.

3) METTRE À JOUR
Remplacer les fichiers sur l'hébergement. La nouvelle version apparaît à la visite suivante (parfois après avoir fermé puis rouvert l'appli). Si une ancienne version persiste, changer le nom du cache dans sw.js (CACHE='accords-v2').

4) EXPORT / IMPORT
Les boutons « Exporter » et « Importer » enregistrent et rechargent la grille (accords, niveau, capo et doigtés choisis) dans un fichier grille-accords.json. Cela fonctionne dans l'appli hébergée ou installée.

5) PARTAGE PAR LIEN
Le bouton « Partager » crée un lien qui contient la grille, le niveau, le capo et les doigtés choisis à la main, puis propose : copier le lien, l'envoyer par e-mail (logiciel de messagerie par défaut), l'ouvrir dans Gmail, ou le partager via le menu du téléphone.
Le lien pointe vers l'adresse où l'appli est hébergée : la personne qui l'ouvre arrive directement sur ta grille. Les données voyagent uniquement dans le lien (après le « # »), elles ne sont envoyées à aucun serveur.
Si tu déplaces l'appli à une autre adresse, les anciens liens partagés ne marcheront plus.
